# 小圆画布视频 XYCut Huabu

把文案、音频或口播视频交给 AI，参考喜欢的模板，制作带字幕、动画和人物画面的视频。

### 预览：[www.xycut.com](https://www.xycut.com/canvas.html)

## 复制使用

把下面这段提示词粘贴给你使用的 AI 助手，并附上文案、音频或带声音的口播视频。

```text
使用 xycut-huabu-skill，把我提供的文案、音频或口播视频制作成画布视频。先提供预览，等我确认后再导出 MP4。

开始前请确认：模板由我到官网选择，还是由你根据内容自动选择；视频做横屏还是竖屏。已有明确要求时直接沿用。

Skill：https://github.com/dayuanlog/xycut-huabu/tree/main/xycut-huabu-skill
未安装请先安装，并读取 SKILL.md。

我本次的素材和要求：
【提供文案、音频或口播视频，可附风格及其他要求】
```

AI 会帮你确认模板怎么选、视频做横屏还是竖屏。

## 想先看看模板？

打开 [www.xycut.com](https://www.xycut.com/canvas.html)，在「画布视频」里查看效果。

喜欢哪套，就复制它的提示词交给 AI，再附上素材。

## 给 Agent

只获取并安装 [`xycut-huabu-skill/`](xycut-huabu-skill/)，读取 [SKILL.md](xycut-huabu-skill/SKILL.md) 后执行。模板选择、比例确认、按需下载及环境准备都在 Skill 内说明，无需用户先研究目录或下载模板库。语音配置见[独立语音](xycut-huabu-skill/references/standalone-speech.md)，继续已有工程见[项目记录](xycut-huabu-skill/references/project-records.md)。不要读取客户端配置，或将密钥写入项目与对话记忆。
