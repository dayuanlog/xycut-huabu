# 横屏制作（默认模式）

新视频没有指定输出比例时采用本模式。已有工程保留原设置；用户明确要求优先。仅要求竖屏封面时，正文仍可保持横屏。

## 默认输出与构图

- 默认1920×1080、16:9；未指定fps的新项目可用30fps，沿用已有项目时保留原fps。渲染参数必须与canvas-plan.json中的output一致，不依赖渲染器的命令行默认值。
- 世界画布组织多块画板，保留既有横屏的左右对照、横向流程、大标题与图解等构图。每块画板的组件数量由语义和阅读时间决定。
- 主体可以是大标题，也可以是完整图形或操作组件。镜头可关注整组、局部按钮、数字或流程节点，不等同于每次把整个画板铺满屏幕。
- 使用共用规范的紧凑排版、空间连续性、焦点交接和两阶段检查。资源的16:9画板不是固定九页或固定主题。

## 标题、封面与字幕

横屏默认不添加固定顶部系列栏，但**默认支持并推荐开启前 5 帧静态封面**（`intro: { frames: 5, duration: 5/fps }`，音频同步预留 `media_timing.audio_lead = 5/fps`），用户可在预览工作台一键开关，或在明确不需要封面时关闭。成品字幕按用户要求或项目已有设置启用。内容中的大标题是语义组件，可以随世界镜头移动。

封面版式与时间契约见[标题、封面与时间偏移](series-titles-and-covers.md)：横屏 16:9 封面采用左右双栏海报构图（左侧标题与信息标签 + 右侧画布预览窗或人物立卡），不照搬竖屏的居中窄版式。

需要字幕时读取[字幕规范](subtitles.md)。无独立framing时，摄影机可以按底部字幕预留缩减可用高度、上移取景中心；字幕模式关闭后恢复相应构图。不要把竖屏中央1:1取景规则强加到横屏。

## 预览与交付

自由浏览使用操作栏以外的可用视口，导出保持计划中的16:9。先完整展开检查画布，再检查实际播放和随机跳转。

先交付并打开HTML，停下来等待用户确认本版预览；确认后按需渲染MP4。按计划显式设置width、height、fps与render查询参数，合入当前音轨。使用本机已有浏览器与工具，不自动下载环境。
