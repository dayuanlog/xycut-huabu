# 竖屏制作（默认竖屏规则）

明确要求竖屏视频、9:16或1080×1920时使用。默认布局为“前置封面＋顶部标题＋中央画布正文＋底部字幕”。用户可以调整或关闭某层；无口播文本的素材任务不编造字幕。

具体标题、期数、文案、素材、金额、主题配色和组件内容属于本次项目，不属于这套版式的固定台词。

本规范管理输出比例与安全区，人物的叙事方式另按[人物口播规范](presenter-video.md)选择。画布主导沿用顶部标题、中央图解、底部字幕；人物主导的全屏讲述允许人物视频铺满9:16画面，叠加简化标题与重点词，字幕继续留在安全区。缩成小窗进入图解后再使用中央画布和固定主副标题，不能把全屏人物误裁成中央1:1方块。

## 输出与固定画面层

- 默认1080×1920、30fps。重点位于中央1:1区域：x=0、y=420、width=1080、height=1080；四周为连续背景，不给正方形增加永久边框或上下黑条。
- 顶部是清晰、足够大的主标题与副标题。系列片可在主标题旁显示期数，单片可不显示期数。采用“系列／主题标识＋本期内容”的层级，不能仍做成很小的标签。
- 顶部标题、底部字幕与世界层分开，固定在屏幕坐标中，不跟随镜头移动。标题区、中央正文区、字幕区互不遮挡。
- 标题和字幕向中央1:1区域靠拢，避开手机界面容易遮住的上下边缘。标题最后一行下沿距中央区上沿约33px；字幕第一行上沿距中央区下沿约30px，两行字幕向下展开，不能反向挤入正文。
- 片内两行标题默认左对齐，容器`top:220px;left:90px;right:90px;gap:25px`。主标题52px、字重750，副标题66px、字重850，两者行高1.2，常规单行组合下沿约y=387。第一行是主标题／系列名与可选数字期数，期数使用另一颜色；第二行是本期副标题。默认不加指南针或其他装饰图标。
- 字幕默认固定上沿`top:1530`、字号43px、行高1.45、左右边距85px、居中排列，最多两行。按实际文字长度检查完整字词与光标边界，不能只检查容器；长标题需重新分行并检查区域，不能挤入正文。其他输出尺寸等比例换算。
- 需要约束边缘内容时只裁剪或柔化世界展示窗口，不能把固定标题和字幕一并裁掉，也不能用遮罩掩盖排版错误。

项目配置：

```json
{
  "presentation_mode": "portrait",
  "output": {"width":1080,"height":1920,"fps":30},
  "framing": {
    "mode":"center-square",
    "content_rect":{"x":0,"y":420,"width":1080,"height":1080}
  }
}
```

该取景矩形属于输出空间。`assets/runtime/camera.js`可据此计算屏幕中心，关闭字幕不应把正文中心从(540,960)推走。自由浏览不受中央取景矩形限制。

## 世界画布与紧凑组件

- 世界中仍采用多个16:9横屏画板，常用1920×1080。每块画板一般放3–4个语义组；配音很短或内容需要时可减少，不为凑数量拆碎句子。
- 组间主要横向展开，并高低错位，例如左上→中下→右上，或反向排列。不要把竖屏等同于把所有组件沿纵向堆成一列、上下滚动。
- 组件紧凑排列，在完整展开后留出必要间距即可。检查实际可见内容和动效范围，不能让标题、图形或说明压到旁边组件；也不能以防重叠为由扩大空隙，再让主体变小。
- 同一画板可混合大标题、金额、网页、视频、文章、地图、操作控件和真实素材。大标题承担主张；有具体关系或操作时设计成小场景。共用规范中的语义组完整入场规则同样适用。
- 网页与手机外框可以表达“网站与视频两个方向”，文章与地图可以表达“内容与路线”。不把所有语义组都做成同一款卡片，也不以无意义弯线连接并列事物。

## 取景与背景虚化

- 主体要足够大。邻近组件只需在侧边或斜侧露出可辨认的一部分，不必全部进入取景。按具体主体与邻居设计关注框和上下文缩放，不只机械适配组件中心。
- 镜头沿组件的高低位置平滑交接，可用弧线、缓入缓出与轻微回收；稳定后停止漂移，阅读时间由实际ASR决定。
- 非当前组件保留完整基础图文并虚化，不能只剩外框。当前组件清晰，轮到哪个语义组就展开它的对应动画。
- 竖屏默认比早期轻虚化更明显：可从最终1080宽画面约4–6px模糊、亮度约0.35–0.45起步。主体尚未出现时可再降低邻居存在感，其他画板比同画板邻居更弱。保留形状与空间联系，但文字不抢眼。
- 可对整组使用CSS `filter: blur(...) brightness(...)`，按镜头切换平滑变化。若过滤发生在世界缩放之前，使用屏幕模糊量除以镜头倍率，避免不同缩放下虚化强度失控。具体强度由实际画面检查，不固定某个案例的数值。

## 封面、标题与字幕默认值

默认在视频最前5帧显示完整静态封面，再进入正文；封面主副标题来自项目配置，副标题最大、最突出。系列片沿用已确认的模板，普通单片也可使用本期主副标题，不硬编码某个系列名称。

封面采用已确认的紧凑文字版式：**主标题、期数、副标题和细横线统一左对齐，整组只做上下居中，不做水平居中。** 重要内容放入竖屏中央16:9横向区域（1080×1920中y=656.25–1263.75），该区域也位于中央1:1内。这里的16:9是封面文字组的安全范围，不改变9:16输出，也不改变正文中央1:1取景。

封面容器左右各留120px（x=120–960），防止平台裁切后文字过于靠边。主标题与期数保持同一行、两种颜色，期数使用阿拉伯数字（第1天、第2天、第12天）；单片没有期数时省略。副标题最突出，可以两行，重点词或数字使用另一颜色。两组文字之间加一根细横线，左端与文字一致，长度接近主标题连同期数的实际文字宽度，不能铺满容器或按副标题宽度拉长。

本地暗色模板的排版默认值：

| 部位 | 1080×1920默认值 |
|---|---|
| 整组位置 | `left:120px;right:120px;top:50%;transform:translateY(-50%);text-align:left`，最终内容完整落在中央16:9内 |
| 主标题与期数 | 64px、字重750、行高1.25、间隔26px；主标题偏浅蓝，期数暖色 |
| 分隔横线 | 2px细线，上下各24px间距；按主标题与期数字形范围测量长度 |
| 副标题 | 136px、字重900、行高1.15；两行间另留12px；普通文字偏白、重点词使用主题强调色 |
| 突出数字 | 可用170px，保留固定排版宽度，不要求每期必须有数字 |

字号是这套模板的默认起点。根据本期真实标题长度调整分行与间距，保持主次、左边距和安全范围；横线须在字体加载后测量主标题与期数的联合文字范围，不能把整行容器宽度当成文字宽度。不要把本例约680px的横线长度硬编码到所有新视频。

默认不加指南针、域名地址框等额外主题图形，也不加冗余说明、巨大期数水印或圆角卡片底板。背景沿用连续的暗色圆点与网格，颜色可按项目主题配置。用户明确提出其他设计时再调整。

默认启用底部画面字幕，采用稳定排版、字词揭示、短暂光标和少量关键词强调。没有ASR文本则不编造字幕；用户指定后续由剪辑软件包装时可关闭本层。详细做法见[字幕规范](subtitles.md)。

封面时长按5/fps计算，不能把“5帧”写成5秒。正文画面、配音、音效、字幕和章节跳转使用同一偏移；原ASR不改写。配置与时间映射必须按[标题、封面与时间偏移](series-titles-and-covers.md)接入本次播放器与混音。

## 验证与导出

先按[共用规范](common-rules.md)完整展开检查每块画板，再在9:16输出中检查实际播放。重点检查主体大小、邻居露出、虚化、入场时的文字残片、金额单位稳定、顶部标题与最长字幕、切页与随机跳转。

确认第0–4帧为封面，第5帧为正文；检查正文锚点与音轨静音前缀、章节和局部预览、片尾自动停止。封面单独检查中央16:9与1:1裁切、120px左右留白、整组上下居中、文字和横线左端一致，以及横线与主标题整行的长度关系。检查片内标题下沿、单行和两行字幕上沿与中央区的距离。字幕模式切换不改变中央正文取景，参考线只用于预览。

导出必须显式采用计划中的width、height、fps，例如本模式默认使用`--width 1080 --height 1920 --fps 30 --query "render=1"`。修改实际fps时同步重算封面时长和音频前缀；不要直接使用渲染器默认60fps。
