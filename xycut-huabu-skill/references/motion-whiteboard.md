# Motion 快节奏白板流规范（16:9 横屏 / 9:16 竖屏）

仅当用户选用 Motion 极客白板流模板（如 `motion-whiteboard-window-16x9` / `motion-whiteboard-window-9x16`），或明确要求「快节奏白板流 / 鼠标框选 / 震动火花冲击」风格时读取本规范；常规画布模板仍按原有规范执行，互不影响。

## 1. 画幅与人物构图
- **16:9 横屏（`1920×1080`）**：
  - 左 65% 为满幅点阵白板工作台（`framing.content_rect` 如 `76, 74, 1216, 856`，配极客顶栏缩放/时间码、左侧工具条、左下声波与实时属性胶囊）；右 35% 为超大圆角人物立卡（约 `556×856`）。
  - 横屏片内默认不放顶部固定视频标题，保留完整 16:9 双栏封面（前 5 帧）。
- **9:16 竖屏（`1080×1920`）**：
  - 不套浏览器/软件外框，采用干净三段式无限画布：顶部固定主标题（`<header id="film-title">`，节点带 `data-preview-text` 与 `data-preview-label`，支持右侧工作台实时修改与显隐开关）+ 中部无边界 `1:1` 饱满主画布（左右均匀留 `~32px` 安全边距，上下柔和羽化遮罩）+ 底部零底影高对比字幕。
  - **人物采用中轴极简双态**：常规画布与鸟瞰期间，固定为画布下沿正中、字幕正上方的 `160×160` 圆形头像（配随口播句段呼吸的电光蓝细光圈），零左右跳动、零方圆乱变；仅在强压场段落沿画面中轴线垂直上浮放大为 `600×800` 居中大竖卡。

## 2. 快节奏镜头与内容渐进呈现
- **高频局部调度（每 2.5–3 秒一动）**：利用 `component.focuses` 将单张内容拆为多个子焦点，镜头切换耗时压缩至 `0.22–0.32s`（采用快切五次缓动 + 甩镜中段轻微动态模糊），避免 7–9 秒静止不动；阶段转折处穿插 `overview` 全局鸟瞰拉远呼吸。
- **先大标题/情境承接，再展开具体清单（严禁提前停在空白列表框里干等）**：
  - 当口播先讲 1–2 句铺垫、情境或引入句，之后才正式列举具体清单/步骤时，**绝不能在讲铺垫句时就提前切出空列表框干等**；
  - 必须先用**大标题文字或情境视觉幕**饱满承接前几句口播，等到口播真正讲到具体清单项的瞬间，再丝滑切换/展开列表并随字用强弹性曲线（`expoOut` / `backOut` / 印章砸落）逐条弹爆；
  - 在 `overview` 全局鸟瞰与自由浏览模式下自动展示完整列表态，确保全局信息完整可读。

## 3. 交互特效、压场与声音细节
- **基于真实 DOM 的鼠标框选与 8 点控制框**：禁止手写硬编码屏幕像素坐标；必须通过 `getBoundingClientRect()` 动态换算 `#stage` 逻辑坐标，并读取 `getComputedStyle(el).flexDirection` / `gridTemplateColumns` 判断横纵排列与网格列数，确保选框、8 个控制点与光标起点/终点在任意缩放倍率与横竖屏下严丝合缝。
- **压场与震动**：关键金句/转折使用全屏深色或品牌蓝微点阵渐变 + 居中大人物 + **人物背后 3 圈同心扩散冲击波纹**（避免生硬截断的灰放射条纹）；强拍处叠加确定性阻尼画面震动（`shakeAt(t)`）与径向粒子火花。
- **音效与零闪烁字幕**：按核心节拍混音高密度短促 UI 音效（`pop / click / tick / whoosh / ding / stamp`，1 分钟约 35–46 处）；若字幕自带高对比深色胶囊底板，务必隐藏 `subtitles.js` 默认 `.canvas-caption-shade` 底部渐变遮罩，消除句间停顿时的阴影闪烁。
