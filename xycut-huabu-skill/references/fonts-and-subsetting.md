# 字体选用、缺字补全与子集打包

模板保持原有字体设计，同时通过「打包迷你子集 + 制作时按需补全完整商免字体」兼顾离线预览还原度与安装包轻量化。

## 1. 模板打包时的字体子集策略（推荐）

- 完整中文字体通常 10–35 MB，直接打进模板 ZIP 会大幅拖慢下载和导入。
- 打包模板副本时，可使用 `fontTools` 对工程实际用到的全部字符（扫描 `index.html`、`canvas-plan.json`、`final-timeline.json`、组件脚本，外加 ASCII 与常用中文标点）生成**示例迷你子集**（通常 ~100–200 KB），直接覆盖打包副本中 `assets/fonts/` 的同名文件。
- **保留原有文件名与 CSS `@font-face` 声明不变**；同时清理 CSS 中未随本模板分发的其他主题 `@font-face` 声明，避免 `package_canvas_template.py` 静态依赖检查报错。
- 在 `project/TEMPLATE_GUIDE.md` 中明确注明：内置字体为示例子集，列出原始完整字体名称与开源许可。

## 2. 制作新视频时遇到缺失或子集缺字的处理流程

用户基于模板输入新文案时，**尽量保持模板原有字体设计**，按以下四级顺序补全字体：

1. **检查字形覆盖**：若模板 `assets/fonts/` 已有字体，先检查其 `cmap`（或用 `fontTools`）是否覆盖本次新文案、标题、封面与字幕的全部字符；完全覆盖则直接复用。
2. **优先查本机缓存与已安装字体**：若检测到缺字或字体文件缺失，先检查本机字体缓存目录或系统已安装字体中是否有同名免费可商用完整字体；找到后直接复制进本次工程 `assets/fonts/` 覆盖同名文件，无需改动 CSS/HTML。
3. **从免费可商用字体库按需下载**：若本机没有，从以下备用免费可商用字体项目查找并下载对应字体，下载后存入本机缓存并拷入本次工程 `assets/fonts/` 覆盖同名文件（同时保留对应字体许可声明）：
   - **备用免费可商用字体仓库（GitHub）**：<https://github.com/wordshub/free-font>（收录含明确授权出处的免费可商用中文字体）
   - *后续补充位*：如配置了国内镜像源或自建字体加速库，优先走国内源，再回退 GitHub。
   - **常见模板字体映射**：
     - 书卷/手账宋体风：思源宋体 `SourceHanSerifCN`（Regular / SemiBold / Heavy）
     - 黑板/课堂手写风：康康手写体 `Kangkang-Handwriting`（或同类商免手写体如霞鹜文楷）
     - 现代科技/潮酷无衬线风：系统无衬线粗体或思源黑体 `SourceHanSansCN`
4. **网络受限优雅兜底**：若环境离线或下载失败，不阻塞制作与预览——保留 `font-family` 中的系统回退字体栈（如 `'Source Han Serif CN','Songti SC','SimSun',serif` / `'KaiTi',cursive` / `'Microsoft YaHei',sans-serif`），正常完成预览并在交付说明中提示用户可补充完整字体文件。
