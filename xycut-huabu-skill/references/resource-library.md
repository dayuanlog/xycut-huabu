# 外部模板与资源使用规范

Skill 提供制作规则和通用运行能力，不内置完整风格模板或示例工程。按当前 Skill 的[外部资源规范](external-resources.md)取得所选模板，沿用入口已经确认的模板来源与任务目录，不重新选择运行模式。不要假定某个内置暗色组件库存在；入口允许不选模板时，也可使用通用运行时根据内容设计。

在新任务目录创建工程副本，保留模板缓存原样。根据包内清单、项目源码和预览确认可用页面、组件、运行时与媒体，不假设统一的目录、组件数量或参数接口。复用时检查依赖与许可，使用稳定 ID 定位，并按本次文案调整设计、布局和动画。

音频或口播视频以本次 ASR 和实际时间为准；模板中的字幕、配音和动画时间仅供参考，不直接用于新作品。通过组件内部动作、镜头和邻近元素共同表达内容，检查整体画布布局与实际镜头画面，避免重叠和遮挡。

若模板提供组件接口，以其自身实现为准；实例应隔离状态和 DOM，文字正确转义，随机定位和逐帧渲染应得到一致结果。模板无法满足需求时可在任务副本中扩展，不修改下载缓存。
